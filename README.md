# Udíme v sudu — Website Redesign

A responsive marketing website redesign for **Udíme v sudu**, a Czech maker of handmade barrel smokers.

The redesign focuses on clear product presentation, trust, readability and a more polished visual identity while keeping the site lightweight and easy to deploy.

## Highlights

- Responsive one-page layout
- Product-focused sections and comparison cards
- Benefits, brand story and contact sections
- Optimized AVIF/WebP image assets
- Subtle reveal and hover interactions
- `prefers-reduced-motion` support
- Lightweight static implementation with no framework required

## Tech

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive CSS Grid / Flexbox

## Project focus

The main goal was to redesign an existing small-business website into a cleaner, more premium presentation that works well on both desktop and mobile. Particular attention was given to typography, spacing, product hierarchy, image performance and conversion-focused calls to action.

## About the brand

Udíme v sudu produces handmade barrel smokers in the Czech Republic. The project is built around a real small-business use case rather than a tutorial or demo assignment.
